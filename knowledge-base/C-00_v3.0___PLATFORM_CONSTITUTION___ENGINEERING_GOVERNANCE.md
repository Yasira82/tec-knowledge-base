# 4. FEDERATED SOVEREIGNTY MODEL

Each application independently owns: UI/UX, Feature execution, Internal workflows, Internal schemas, Business models, Domain-specific logic.

Apps MUST consume: Identity Runtime, Payment Runtime, Pi Abstraction Layer (PAL), Shared Event Contracts, Observability Standards, Governance Rules, Security Policies.

Apps MAY NOT override shared runtime contracts.

# 5. SHARED RUNTIME OWNERSHIP

```

on raw Pi SDK behavior long-term.
```

## ADR-007 Rule

```
FOREIGN_SESSION=true
DOES NOT guarantee valid ownership authority.
```

Therefore: Mode 2 requires ownership validation. Mode 1 remains safe fallback.
