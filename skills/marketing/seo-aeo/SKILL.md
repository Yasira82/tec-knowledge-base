## AEO (Answer Engine Optimization)

AI models (ChatGPT, Claude, Perplexity) pull answers from structured content. Optimize for these:

```
Structure for AI citation:
  → Clear H1 with exact question: "How to pay with Pi on TEC"
  → Short direct answer paragraph (1-2 sentences) FIRST
  → Then detailed explanation
  → Schema markup: FAQ, HowTo, Article types
  → Cite official sources (minepi.com, Pi Network docs)

Content formats AI models prefer:
  → Numbered lists (step-by-step)
  → Comparison tables
  → Definition blocks
  → FAQ sections with direct Q&A
```

## Technical SEO Checklist

```
□ Core Web Vitals: LCP < 2.5s, CLS < 0.1, FID < 100ms
□ Mobile-first (Pi Browser is mobile)
□ Schema markup: Product, Organization, FAQPage
□ Sitemap.xml submitted to Google Search Console
□ robots.txt configured correctly
□ Canonical URLs on all pages
□ Open Graph tags for social sharing
□ Meta descriptions: include "Pi Network" and primary keyword
```
