# TEC Community Marketing

## Pi Community Channels

| Channel | Audience | Best For | Reach |
|---------|----------|----------|-------|
| **Pi Chat (in-app)** | Active miners | Announcements | Highest (in Pi Browser) |
| **Pi Forum** | Engaged community | Long-form education | Medium |
| **Telegram** | Global pioneers | Support + updates | High (multilingual) |
| **Twitter/X** | Crypto-aware | PR + credibility | Medium |
| **Pi Developer Forum** | Builders | Technical updates | Low (niche) |

## Ambassador Program Framework

```
Tiers:
  Pioneer Ambassador   → share content + refer 5+ users → FREE Hub PRO
  Merchant Ambassador  → onboard 3+ merchants → reduced transaction fees
  Builder Ambassador   → integrate TEC SDK → priority API access

Incentives (Pi-denominated):
  → Referral: 0.1 Pi per activated referral
  → Content: Pi bounty for community tutorials
  → Merchant: 0.5% fee waiver for first 30 days
```

## Community Trust Building

```
Do:
  ✓ Open source code (GitHub public repos)
  ✓ Regular transparency updates (weekly in Pi Chat)
  ✓ Show real transaction data (GMV, users, merchants)
  ✓ Respond to every critical feedback within 24h
  ✓ Acknowledge bugs publicly and show fix timeline

Don't:
  ❌ Delete negative comments
  ❌ Promise features not yet built
  ❌ Ignore support requests > 48h
  ❌ Use marketing language that sounds like scams
  ❌ Make Pi price predictions
```

## Community Content Calendar

```
Weekly:
  Monday    — "This week on TEC" (product update)
  Thursday  — "Pioneer Spotlight" (merchant/user story)

Monthly:
  Week 1   — Platform metrics report
  Week 3   — "Ask TEC Anything" session

Ad hoc:
  — Pi Network mainnet milestones → TEC celebration post
  — Major feature launch → demo + tutorial
  — Bug/incident → transparency post within 1h
```

## Multilingual Strategy

```
Priority languages (Pi community distribution):
  1. English     — global
  2. Arabic      — MENA (large Pi community)
  3. Spanish     — LatAm
  4. Chinese     — significant Pi miner base
  5. Vietnamese  — active Pi community

Approach:
  → Core content in English
  → Key announcements translated to Arabic + Spanish
  → Community moderators (native speakers) per region
```
