# Launch Posts

Ready-to-publish posts for X/Twitter, Telegram, and Pi community channels. Each is
built from the app's value proposition (SSoT: `tec-app/src/domains/_registry.ts`).
Honesty rules in `README.md` apply — never add a number you can't back up.

## Template (copy, fill, post)

```
{emoji} {App} is live on Pi.

{one-line value prop}

{one concrete thing you can do today}

Open it in Pi Browser → {app}.tecosystem.app
Part of TEC — 24 apps, one Pi identity. Become a Founding Pioneer: hub.tecosystem.app/pioneers
```

- Keep it to 3–4 short lines for X. Telegram can carry the extra CTA line.
- For preview/gated apps (FundX, Insure, Brookfield, Estate, Titan, VIP, Elite,
  Legend, Epic, NX, Zone V1, System, DX) say **"preview"** — do not imply live money.
- Always end with the Pioneers CTA so every app post feeds the funnel (C-133).
